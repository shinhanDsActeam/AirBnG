## 🔎 소개
**에어비앤짐**은 여행자가 짐을 맡기고, 개인이 짐을 보관해주는 공유 서비스입니다.

여행지에서 무거운 짐 때문에 고생하지 마세요.  
근처에 있는 사람들이 자신의 집, 사무실, 가게에서 안전하게 짐을 보관해드립니다.

짐을 맡기고 싶은 여행자는 앱에서 위치와 맡기고 싶은 짐 종류를 선택하고,  
짐을 보관해줄 개인은 공간을 제공하고 수수료를 받습니다.  
카페, 편의점 같은 상업 시설뿐만 아니라 일반 개인도 호스트가 되어 부수입을 올릴 수 있어요.
